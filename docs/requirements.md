# 国位置クイズ 要件

## 目的
スマホのブラウザで遊べる国位置クイズで、世界の全197か国の位置を覚える。

## 対象
- 日本が承認している196か国＋日本の **197か国**
- 表記は日本語（国名・首都・豆知識）

## 基本の遊び方
1. 地図上で出題する国をハイライトし、その国まで自動でズームする
   - 小さい国（島国・バチカンなど）は丸で囲んで位置を示す
2. 8つの国名から答えを選ぶ
   - 間違いの選択肢は、近くの国（同じ地域・隣の国）を中心に選ぶ
3. 正解・不正解を表示する。不正解のときは正しい国名を示す
4. ヒントボタンで、国旗 → 首都 → 豆知識 の順に1つずつ見られる

## 地図の色分け
| 状態 | 色 | 条件 |
|---|---|---|
| まだ覚えていない | 灰色 | まだ正解していない |
| ヒントありで正解 | 赤 | ヒントを1つ以上見てから正解した |
| ヒントなしで正解 | 金 | ヒントを見ずに正解した |

- 赤の国をヒントなしで正解すると金になる
- 色が下がることはない（金の国を間違えても金のまま。ただし苦手な国として記録する）
- 出題中の国は、上の3色と区別できる色（青系）でハイライトする
- **最終ゴールは全197か国を金にすること**

## 出題モード
次の3つを組み合わせて選べる。
- **出題範囲**：全世界 / 地域別（アジア・ヨーロッパ・アフリカ・北米・中南米・オセアニア）
- **出題順**
  - ランダム
  - 未習得だけ（灰色と赤の国）
  - 苦手な国を優先（間違えた回数が多い国・赤の国を多めに出す）
- **答え方**
  - 地図を見て国名を選ぶ（8択）
  - 逆モード：国名を見て地図の国をタップする（小さい国はタップできる範囲を広めにとる）

## 画面
- **クイズ画面**：上に地図、下に選択肢（2列×4段）。片手で押せる配置
- **進捗画面**：色分けした世界地図、金・赤・灰色の国数、地域ごとの達成率
- **国の一覧（図鑑）**：国旗・首都・豆知識を見返せる
- **設定**：出題モードの選択、進捗のリセット

## データ
- 地図：Natural Earth（小さい国も含まれる縮尺のもの）
- 国旗：SVG 画像（国旗の絵文字は端末によって表示されないため使わない）
- 国の情報：国名・首都・地域・豆知識（1か国2〜3行）を1つのデータファイルにまとめる。下書きは Claude が作り、あとで直せるようにする
- 地図データの国・地域の分け方と197か国の対応表を用意する

## 保存
- 進捗はブラウザ内（localStorage）に保存する。ログインはなし
- 国ごとに「色の状態」「正解回数」「不正解回数」「最後に出題した日時」を記録する

## 技術構成
- Vite + TypeScript の静的サイト、地図の描画は D3（d3-geo）
- GitHub Pages で公開する
